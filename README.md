# cyber-portfolio

This portfolio documents my practical cybersecurity learning as I prepare for CompTIA Security+. My current focus is Linux fundamentals, virtualisation, security concepts, authentication logs, and defensive security foundations.

## Current Labs

### 01 - Ubuntu VM Home Lab
Built an Ubuntu virtual machine in VirtualBox with NAT networking and a clean base snapshot to create a safe testing environment.

### 02 - CIA Triad in Ubuntu
Practised Linux file permissions, SHA-256 hashing, and backup/restore commands to demonstrate confidentiality, integrity, and availability.

### 03 - Linux Authentication Logs
Reviewed Linux login and privilege activity using `who`, `w`, `last`, and `/var/log/auth.log`, mapping findings to authentication, authorisation, and accounting.
